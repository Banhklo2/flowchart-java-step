# 🚶 FlowChart Step Counter

**FlowChart로 걸음 수 누적 계산 로직을 설계하고 Java로 구현한 연습**

---

## ✅ 시나리오: 하루 동안 걸음 수 합산 프로그램

- 사용자가 만보기처럼 자신의 걸음 수를 계속 입력한다.
- 각 입력은 **이번 구간에서 걸은 걸음 수(step)** 이다.
- 사용자가 **0을 입력하면 입력을 종료**하고,
  **총 걸음 수(totalSteps)** 를 출력한다.

---

## 📌 입력 / 출력 정리

### 입력(Input)
- 걸음 수 `step`

### 출력(Output)
- 총 걸음 수 `totalSteps`

### 상태(State)
- `totalSteps` : 지금까지 입력된 걸음 수의 합

---

## 🔎 조건 정리

### 종료 조건
- 입력값이 `0`인 경우

### 분기 조건
- 입력값이 0인가 / 0이 아닌가

### 예외 / 에러 조건
- (선택) 음수 걸음 수 입력 시  
  → 경고 출력 후 다시 입력받기

---

## 🔁 로직 흐름 설계

1. 시작 시 한 번만 실행
   - `totalSteps = 0`
   - `step = 0`

2. 반복
   1) 걸음 수 `step`을 입력받는다.  
   2) 입력값이 `0`인지 확인한다.  
      - 예 → `totalSteps` 출력 후 반복 종료  
      - 아니오 → 다음 단계 진행  
   3) 걸음 수 누적  
      - `totalSteps = totalSteps + step`  
   4) 다시 걸음 수 입력 단계로 돌아간다.

3. 종료 시
- 총 걸음 수 `totalSteps` 출력
- 프로그램 종료
